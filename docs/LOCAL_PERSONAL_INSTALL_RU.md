# Личная установка SchoolSphere

Эта инструкция предназначена для одного человека, который хочет импортировать подготовленный курс и заниматься на своём компьютере. Создавать школу или настраивать сервер не нужно.

## Что понадобится

- Компьютер с Windows, macOS или Linux.
- Docker Desktop для Windows/macOS либо Docker Engine и Compose v2 для Linux. При первом запуске Docker попросит скачать компоненты проекта; это может занять несколько минут.
- Свободное место на диске для приложения, образов и базы курсов.

## Запуск

1. Установите и запустите Docker Desktop. Дождитесь, пока он покажет, что Docker запущен.
2. На странице проекта GitHub нажмите **Code → Download ZIP**, затем распакуйте скачанный архив в обычную папку.
3. Откройте эту папку и запустите **Start SchoolSphere**:
   - Windows: дважды щёлкните `Start SchoolSphere.bat`.
   - macOS: дважды щёлкните `Start SchoolSphere.command`. При первом запуске macOS может заблокировать файл: нажмите на нём правой кнопкой мыши, выберите **Открыть**, затем подтвердите действие.
   - Linux: запустите `scripts/local-school.sh` из терминала или файлового менеджера. Если система спросит, разрешите запуск файла как программы.
4. Дождитесь сообщения о готовности. Установщик откроет сайт по адресу [http://localhost:3001](http://localhost:3001).
5. На странице входа выберите **Войти как ученик**. Это локальный демонстрационный вход, пароль вводить не нужно.
6. Чтобы добавить личный курс, откройте импорт курса в кабинете ученика и выберите файл `.s84course`. Если у вас только репозиторий GitHub, сначала попросите своего агента подготовить из него пакет по [инструкции для агента](COURSE_PACKAGE_AGENT_WORKFLOW.md).

При первом запуске установщик создаёт локальный `.env` с уникальными секретами и демонстрационными параметрами. Файл остаётся на компьютере и не перезаписывается при следующих стартах. Если `.env` уже был в папке, установщик использует его настройки как есть. Приложение и база доступны только на этом компьютере. Не меняйте привязку портов на сетевую и не используйте демонстрационный вход для опубликованного в интернете сайта.

## Остановить и продолжить

Дважды щёлкните **Stop SchoolSphere** (`Stop SchoolSphere.bat` на Windows, `Stop SchoolSphere.command` на macOS). В Linux выполните `scripts/local-school.sh stop`. Остановка сохраняет импортированные курсы и прогресс. Чтобы продолжить, снова запустите **Start SchoolSphere**.

Не удаляйте папку `school84-db` в Docker Desktop, если хотите сохранить обучение. Установщик повторно проверяет базу при старте: пустая база получает схему, а существующая база не синхронизируется и не переинициализируется. Примерный учебный аккаунт добавляется только вместе с первой настройкой пустой базы; старые базы не получают автоматическую демо-учётную запись. Повторные запуски не сбрасывают прогресс.

## Если запуск остановился

- **Docker не найден или не запущен.** Установите Docker Desktop, откройте его, дождитесь готовности и повторите запуск.
- **Сборка долго не меняется.** Первый запуск скачивает и собирает несколько образов. Оставьте Docker запущенным и проверьте интернет-соединение и место на диске.
- **Порт 3001 занят.** Закройте другое локальное приложение на этом порту и повторите запуск.
- **Обнаружена неизвестная база.** Установщик намеренно не меняет схему существующей базы. Не удаляйте том. Сохраните резервную копию и попросите технического помощника проверить [инструкцию по локальному запуску](LOCAL_DEVELOPMENT.md).
- **Сайт не открылся автоматически.** Откройте [http://localhost:3001](http://localhost:3001) вручную. Если страница недоступна, попросите технического помощника проверить журнал командой `docker compose logs app python-runner`.

## Удаление

Удаление распакованной папки само по себе не удаляет базу, хранящуюся в Docker. Чтобы позже продолжить обучение, сохраните папку проекта и используйте кнопку остановки. Удаление данных Docker необратимо удалит курсы и прогресс.
