# Формат пакета курса School84

Файл `.s84course` — ZIP-архив. Внутри находится обязательный `manifest.json`, файлы ресурсов в `assets/` и, по желанию, отдельный `progress.json`.

Такой пакет можно сгенерировать локально, импортировать в School84, снова экспортировать и импортировать в другой экземпляр. При импорте создаётся новый курс со статусом `DRAFT` и новыми внутренними ID. Пакет не переносит Stripe ID и данные отправленных ученических решений.

## Структура архива

```text
course.s84course
├── manifest.json
├── progress.json       # необязательно; добавляется только по выбору автора
└── assets/
    ├── <sha256-prefix>.png
    └── <sha256-prefix>.mp4
```

Версия формата задаётся парой `format: "school84.course"` и `formatVersion: 1`. Неизвестные поля и версии отклоняются. Порядок глав, уроков, ячеек, вопросов и ответов задаётся их положительным целым `position`.

## Манифест

Верхнеуровневые поля:

- `course`: название, описания, цена в центах, длительность, уровень, slug, названия категорий и необязательная обложка.
- `chapters`: главы с уроками в порядке `position`.
- `assets`: таблица файлов. Для каждого ресурса указываются `path`, MIME-тип, размер в байтах и SHA-256 hex digest.
- `settings.grading.standardInputOutput`: должен быть `true`; сравнение входов/выходов всегда поддерживается.
- `settings.grading.authorChecks`: должен соответствовать наличию `checkerCode` в задачах.

У урока есть название, описание, позиция, необязательный видеофайл, legacy quiz и список ячеек. Поддерживаемые ячейки:

- `TEXT`: `textContent` хранит JSON документа редактора или обычный текст. Ссылки на inline-изображения используют `attrs.key` и `attrs.src` со значением пути, например `assets/abc123.png`.
- `CODE_TASK`: условие, начальный код, примеры, тестовые случаи и `lintConfig`.
- `QUIZ`: вопросы и варианты ответов с `isCorrect` и необязательным объяснением.

Legacy quiz находится в `lesson.legacyQuiz`; для нового содержимого используйте quiz-ячеки. Вопросы и ответы сериализуются целиком, включая правильные варианты.

Пример задачи:

```json
{
  "type": "CODE_TASK",
  "position": 2,
  "title": "Сложение",
  "taskPrompt": "Прочитайте два числа и выведите их сумму.",
  "starterCode": "print(sum(map(int, input().split())))",
  "examples": [{ "input": "2 3\n", "output": "5\n" }],
  "testCases": [{ "input": "2 3\n", "output": "5\n" }],
  "lintConfig": {
    "language": "python",
    "linters": ["ruff"],
    "checkerCode": "def check(input_text, expected_output, actual_output, source_code):\n    return actual_output.strip() == expected_output.strip()"
  }
}
```

`language` поддерживает `python` и `javascript`. Для Python доступен Ruff (`"linters": ["ruff"]`), для JavaScript — ESLint (`"linters": ["eslint"]`); пустой список отключает линтер. Старый вид `{ "python": ["ruff"] }` сохраняет совместимость.

Checker необязателен и запускается дополнительно к стандартному сравнению вывода для каждого теста:

- Python: определить `check(input_text, expected_output, actual_output, source_code)`.
- JavaScript: определить `check({ input, expectedOutput, actualOutput, sourceCode })`.
- Вернуть `true` для принятия, `false` для отказа либо строку: пустая строка принимает, непустая отклоняет задачу и показывается как сообщение.

Проверки запускаются без сети в ограниченных контейнерах. Решение и checker исполняются в разных контейнерах.

## Ресурсы и ограничения

Путь ресурса должен быть безопасным относительным путём из `assets/`; каждый такой файл должен быть объявлен в `assets` и иметь совпадающие размер и SHA-256. Поддерживаются PNG, JPEG, WebP, GIF, AVIF, MP4, WebM и QuickTime. Максимальный размер одного ресурса — 100 MiB, всех ресурсов вместе — 125 MiB, манифеста — 16 MiB, файла прогресса — 16 MiB, архива — 100 MiB, распакованного содержимого — 160 MiB. Одновременно принимается один импорт пакета.

## Прогресс

Необязательный `progress.json` имеет формат `school84.course-progress`, версия 1. У каждого ученика указаны email, завершённость уроков и статусы ячеек с числом попыток. Позиции главы/урока/ячейки используются для сопоставления, поэтому их нужно сохранить при преобразовании курса.

При импорте записи применяются только к ученикам с совпадающим email и ролью `STUDENT` в выбранной организации. Для них создаётся активный enrollment. Неизвестные ученики и отсутствующие позиции пропускаются с предупреждением. Файл не содержит код решений, отправленные ответы quiz или сами адреса сверх необходимого для сопоставления.

## Импорт и экспорт

Экспорт доступен в настройках курса на `/teacher/courses/<courseId>/edit`. Импорт доступен на `/teacher`: загрузите `.s84course`/ZIP или укажите GitHub URL вида `https://github.com/<owner>/<repo>/blob/<ref>/<path>.s84course` (либо URL `raw.githubusercontent.com`). GitHub-импорт принимает прямую ссылку на файл архива, не ссылку на каталог репозитория.
