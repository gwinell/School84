# Data Science с нуля

Импортируемый русскоязычный маршрут SchoolSphere для начинающих от 16 лет. В курс встроены объяснения, данные, примеры, автопроверяемые упражнения, рубрики и проекты. Ученик не должен переходить в GitHub или искать внешние учебные материалы.

- 13 глав, 115 уроков, 121 вопрос с одним ключом ответа, 29 встроенных Python-задач.
- Оценка нагрузки — около 164 часов.
- NumPy, Pandas, scikit-learn и графики выполняются в локальном JupyterLab по командам курса; выполнение библиотек внутри стандартного CODE_TASK runner не поддерживается.
- Итоговый проект использует самогенерируемый набор из 120 искусственных строк и завершает обучение обязательным локальным Docker API-прогоном. Публичное облако не требуется.

## Файлы

- `manifest.json` — редактируемый исходник.
- `data-science-s-nulya.s84course` — ZIP-пакет для импорта.
- `COVERAGE.md` — оценка покрытия учебных единиц источников и неравномерности глубины.

## Пересборка и проверка

Из этой папки соберите пакет:

```bash
python3 -m zipfile -c data-science-s-nulya.s84course manifest.json
```

В корне SchoolSphere запустите валидатор и тесты пакета:

```bash
pnpm course-package:validate courses/data-science-s-nulya/data-science-s-nulya.s84course
node --test tests/course-package.test.cjs tests/course-package-validator.test.cjs
```

Встроенная среда автопроверки рассчитана на обычный stdin/stdout Python без сторонних библиотек. Не вставляй NumPy/Pandas/sklearn-примеры в CODE_TASK; запускай их локально по инструкции курса.

## Правило разработки и проверки

Каждый курс проходит последовательный цикл четырёх независимых ролей: методист, технический специалист, ученик-тестер без опыта программирования и аудитор покрытия источников.

1. **Методист** пишет объяснения, формулы, графики/данные, примеры, упражнения и ответы по первичным источникам. Все сведения и данные для задания включаются в курс; обязательного перехода в репозиторий или поиск нет.
2. **Технический специалист** проверяет факты, расчёты, ответы, Python-код и совместимость с форматом. Он запускает доступные автотесты и линтеры. Ошибки возвращаются методисту, затем перепроверяются.
3. **Ученик-тестер от 16 лет без опыта программирования** проходит материалы только по курсу. Вопросы, неясные слова, ошибки настройки и недостающие данные возвращаются методисту; после исправления ученик проходит затронутые шаги снова.
4. **Аудитор покрытия** сопоставляет цели курса с исходными модулями/главами/неделями и отдельно фиксирует полные, частичные и отсутствующие цели. Это не процент скопированных файлов и не доказательство усвоения.

Нельзя заявлять, что настоящий ученик прошёл курс или научился по нему, если реальный ученик его не проходил. До пилота с человеком отчёт агента-новичка считается симулированным usability-review, не фактом обучения.

## Проверки этой версии

- 13 глав, 115 уроков, 257 ячеек, 121 вопрос и 29 CODE_TASK.
- У каждого вопроса ровно один правильный ответ; позиции глав/уроков/ячеек/ответов непрерывны.
- 64 блока Python и 29 starter-кодов прошли синтаксический разбор AST.
- ZIP-пакет собран и прошёл проверку целостности.
- Встроенные задачи используют только стандартный Python. Пакеты для локальных ноутбуков отсутствовали в среде статической проверки; поэтому все NumPy/Pandas/sklearn примеры здесь не отмечаются как выполненные.
- Кандидат проверен четырьмя независимыми агентами: методистом, техническим специалистом, новичком и аудитором источников.
- Живой импорт пакета в SchoolSphere не подтверждён. Docker CLI есть в среде, но запущенного Docker daemon нет, поэтому сборка/запрос контейнера пока не запускались.
- Реальный ученик 16+ ещё не проходил курс; фактический результат обучения не заявляется.

Ключи quiz включены в архив по формату SchoolSphere; вопросы служат для формирующей проверки, не для защищённого экзамена.
