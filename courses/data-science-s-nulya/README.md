# Data Science с нуля

Импортируемый русскоязычный курс SchoolSphere для начинающих от 16 лет. Маршрут и обязательная практика находятся внутри курса; ученику не нужно открывать GitHub, искать объяснения или решать задания во внешних репозиториях.

- 7 глав, 27 уроков, 33 проверочных вопроса и 8 встроенных Python-задач и локальный ML/API-проект с полным кодом.
- Ориентировочная длительность — около 35 часов.
- В уроки включены формулы, разобранные примеры и синтетическая таблица данных для практики.
- Итоговый проект выполняется по инструкции и рубрике внутри курса. Облачная среда и платные сервисы не требуются.

## Файлы

- `manifest.json` — редактируемый исходник курса.
- `data-science-s-nulya.s84course` — архив для импорта в SchoolSphere.

## Пересборка и проверка

Из этой папки соберите архив:

```bash
python3 -m zipfile -c data-science-s-nulya.s84course manifest.json
```

Из корня SchoolSphere проверьте его встроенным валидатором и тестами:

```bash
pnpm course-package:validate courses/data-science-s-nulya/data-science-s-nulya.s84course
node --test tests/course-package.test.cjs tests/course-package-validator.test.cjs
```

Ключи ответов входят в импортный архив согласно формату SchoolSphere. Вопросы предназначены для формирующей проверки, не для защищённого экзамена.

## Правило разработки и проверки курса

Каждый курс проходит последовательный цикл с тремя ролями: методист, технический специалист и начинающий ученик-тестер (от 16 лет, если не задано иначе).

1. **Методист проектирует обучение.** Пишет теорию, формулы, примеры, задачи и разборы. Основу содержания составляет исследование первичных источников, указанных заказчиком. Материал пересказывается своими словами с соблюдением лицензий и атрибуцией. Все сведения, нужные ученику для ответа и выполнения задачи, включаются в урок. Нельзя отправлять ученика в репозиторий или поиск за недостающими объяснениями, данными либо заданиями; ссылки на источники служат редакционной документацией и не являются частью обязательного маршрута ученика.
2. **Технический специалист проверяет до тестирования учеником.** Сверяет факты, формулы, расчёты, графики, примеры, ответы, код и требования источников. Запускает автопроверки, тесты задач и линтеры. При дефекте возвращает методисту конкретное замечание; после исправления проверяет снова. К ученическому тестированию переходят после устранения блокирующих дефектов.
3. **Новичок-тестер проходит курс без подсказок.** На старте он не знает программирования. Он использует только объяснения, примеры, данные, инструменты и задания, включённые в курс. Фиксируются непонятные термины, недостающие сведения, вопросы, ошибки среды и неясные инструкции.
4. **Вопросы тестера возвращают урок методисту.** Каждое затруднение записывается с уроком и шагом. Методист исправляет материал, технический специалист повторно проверяет его, затем новичок заново проходит затронутую часть. Цикл повторяется, пока задание нельзя выполнить без незапланированного поиска и помощи.
5. **Обучение подтверждается реальным прохождением.** Фиксируются выполненные задания, ошибки и исправления, вопросы ученика, входные и итоговые проверки, проект и рубрика. Нельзя заявлять о проверке учеником или эффективности курса, если новичок его не прошёл; отсутствие такого прогона отмечается явно.

Для курса сохраняется краткий отчёт: версия источников, замечания и их закрытие, результаты автопроверок, прохождение новичком и известные ограничения.
